# 🍔 McDev’s Burger

> Sistema web para uma hamburgueria, desenvolvido como projeto prático de aprendizado Full Stack.

O **McDev’s Burger** tem como objetivo desenvolver uma aplicação web completa, conectando uma interface moderna a uma API própria e a um banco de dados relacional.

O projeto será desenvolvido utilizando tecnologias modernas do ecossistema JavaScript e TypeScript, aplicando boas práticas de organização, validação, segurança e arquitetura de software.

## 🚀 Tecnologias

- **Front-end:** React 19 + TypeScript
- **Back-end:** Node.js + TypeScript
- **Banco de dados:** PostgreSQL
- **ORM:** Prisma
- **Versionamento:** Git e GitHub


## 🛠️ Arquitetura

A aplicação será organizada em camadas, separando as responsabilidades do front-end, do back-end e do banco de dados.

```text
McDevs-Burger/
├── frontend/       # Interface com React
├── backend/        # API com Node.js
└── README.md       # Documentação do projeto
```


## 📚 Objetivo do projeto

Consolidar conhecimentos em desenvolvimento Full Stack, integração entre aplicações, APIs REST, bancos de dados relacionais, autenticação, testes e publicação de aplicações.
